WRF model configuration

This page summarises the configuration used for the five-day Etesian case. Values for the 1 km domain have been checked against the metadata in the completed WRF output files.

Model, domains and forcing

ModelWRF v4.3.3. The output files are identified as a WRF-Chem v4.3.3 build.
Simulation period11 August 2026 00:00 UTC to 17 August 2026 00:00 UTC. The first 24 hours are treated as spin-up; the following five days are analysed.
Initial and boundary conditionsERA5 reanalysis, supplied at hourly intervals.
NestingThree two-way nested Lambert conformal domains centred near 38.25° N, 24.25° E.
Horizontal gridd01: 9 km, 101 × 101 points; d02: 3 km, 121 × 121 points; d03: 1 km, 181 × 181 points.
Vertical grid81 eta levels in d03, with terrain-following coordinates and refined spacing near the surface.
Time step2.67 s in d03, with a 1:3 time-step ratio between successive domains.

Physical parameterizations

MicrophysicsThompson scheme (mp_physics = 8).
Long-wave radiationRRTMG (ra_lw_physics = 4).
Short-wave radiationRRTMG (ra_sw_physics = 4), called every 10 minutes.
Land-surface modelNoah land-surface model (sf_surface_physics = 2).
Surface layerMYNN surface-layer scheme (sf_sfclay_physics = 5).
Planetary boundary layerMYNN 2.5-level TKE scheme (bl_pbl_physics = 5), with TKE advection enabled.
Cumulus parameterizationKain-Fritsch in d01 only (cu_physics = 1, 0, 0).
Land categories and soil layersMODIS 21-category land use and four soil layers.

Paired wind-farm experiments

CTRLReference simulation without the wind-farm parameterization (windfarm_opt = 0, 0, 0).
WF-existingSimulation with the Fitch wind-farm parameterization enabled only in d03 (windfarm_opt = 0, 0, 1).
Turbine-generated TKE factorwindfarm_tke_factor = 0.25.
Shared settingsBoth simulations use the same domains, physics, initial and boundary conditions, and WRF executable.
